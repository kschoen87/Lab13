  \caption{Splunk results for Event Code 1.}
  \label{fig:evencode1-results}
\end{figure}
\medskip
\begin{notebox}
  \textbf{Why use a forwarder?} \\
  There are many reasons why you might use a forwarder instead of pulling directly from a machine such as
  architecture limitations, efficiency and reliability, but the primary reason is scalability. In an 
  enterprise environment, there will be dozens or endpoints. To install and check each on individually would
  be a time-consuming nightmare. Instead, we have a central server that each machine will forward log to. From 
  the central server, we can manage and analyze all the logs in one place.
\end{notebox}

\section{ART \& SPL}
\medskip
\begin{notebox}
  In this section, we will generate events with Atomic Red Team and write SPL queries to analyze them.
\end{notebox}
\subsection{ART Setup}
\begin{figure}[H]
  \centering
  \includegraphics[width=0.75\linewidth]{images/atomicrt-showdetails.png}
  \caption{Confirmation of Atomic Red Team installation.}
  \label{fig:atomicrt-showdetails}
\end{figure}
\medskip
\begin{impactbox}
For my test, I selected T1016 - Network Configuration Discovery. I picked this technique because 
it is a common tactic used by adversaries to gather information about the network environment and 
because it seemed interesting and relevant to the goals of this lab.
\end{impactbox}
\subsection{SPL Queries}
\medskip
\textbf{Query 1:} \\
\begin{figure}[H]
  \centering
  \includegraphics[width=0.75\linewidth]{images/query1.png}
  \caption{SPL query 1}
  \label{fig:query1}
\end{figure}
\begin{impactbox}
  This query searches for encoded PowerShell commands. T1016 uses commands that poke at a system
  to find configuration information but does not use any encoded inputs. The query result shown is most
  an artifact from the T1059.001 test ran earlier.
\end{impactbox}
\newpage
\textbf{Query 2:} \\
\begin{figure}[H]
  \centering
  \includegraphics[width=0.75\linewidth]{images/query2.png}
  \caption{SPL query 2}
  \label{fig:query2}
\end{figure}
\begin{impactbox}
  This query checks for process frequency to aid in identifying anomalous behavior. Searching though the
  final pages of the results (where we start seeing single occurrences of processes) we can see our anomalous
  powershell.exe process.
\end{impactbox}

\textbf{Query 3:} \\
\begin{figure}[H]
  \centering
  \includegraphics[width=0.75\linewidth]{images/query3.png}
  \caption{SPL query 3}
  \label{fig:query3}
\end{figure}
\begin{impactbox}
  This query is designed with the T1016 technique specifically in mind. Because we know this attack will attempt
  to gather network information, \texttt{ipconfig} is the most relevant command to look for and because it is not
  a command commonly used by people outside of IT, the query would return minimal results. The top four results
  are from myself generating traffic to test forwarding. Our last two results are clearly from our ART test; the 
  two results coinciding with each other. The final result shows the \texttt{cmd.exe} file being executed through 
  PowerShell, which includes \verb|ipconfig/all| from the result before.
\end{impactbox}
